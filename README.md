Mohamed — Work Log
A personal portfolio site showcasing self-taught programming work: network
security tools, games, and software experiments. Built as a single static
HTML page.
About
I'm a self-taught developer based in Chlef, Algeria, working across Python,
C++, C#, GDScript, and Three.js. This site is a visual log of what I've
built so far — partly for anyone who wants to see the work, partly to keep
track of it myself.
Projects featured
NetRadar Pro — cross-platform network + Bluetooth scanner with a live
animated radar GUI
Security Shield — multi-layered antivirus combining hash detection,
VirusTotal, and heuristic analysis
AI Agent Hub — voice + Claude API assistant with network scanning and
a web dashboard
Corrupted Pages Sanctuary — a four-chapter horror game built in
Godot 4.3
3D Flappy Bird — a browser-based 3D game built with Three.js
Plus a few concepts still in progress (VPS Sentinel, a gaming showcase
site, an interactive calculator)
Built with
HTML / CSS (single file, no build step)
Hand-drawn SVG illustrations for each project
Fonts: Space Grotesk, IBM Plex Sans, IBM Plex Mono
Running locally
No dependencies, no build tools. Just open the file directly:
```bash
open index.html
```
Or serve it locally if you prefer:
```bash
python -m http.server 8000
```
Then visit `https://karle852.github.io/Mohamed-Work-Log/`.
